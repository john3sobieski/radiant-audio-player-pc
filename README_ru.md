## Чем Radiant лучше

Большинство плееров требуют вход в аккаунт, стриминг или показывают рекламу. Radiant наоборот: он играет **ваши** файлы из **вашей** папки и ничего не делает за вашей спиной.

- **Приватность по умолчанию.** Нет рекламы, аккаунтов, аналитики и телеметрии. Всё остаётся на вашем компьютере. Интернет нужен только для загрузки ИИ-модели, и только по нажатию кнопки.
- **ИИ-разделение на стемы без интернета.** Разделите любой трек на вокал, барабаны, бас и остальное и сохраните минусовку, только вокал или любую смесь одним WAV-файлом. Всё считается на вашем ПК (процессор или видеокарта), ничего не отправляется.
- **Блокировка приложения.** Защитите программу 4-значным, 6-значным или своим кодом. Сам код не хранится, только хэш с солью. Неверные попытки замедляются, а файл восстановления из 12 слов вернёт доступ, если код забыт.
- **Настоящая настройка звука.** 12-полосный эквалайзер и 10 пресетов, отдельная кривая для каждого трека (по желанию), бас и высокие, субзвуковой фильтр, нормализация громкости, моно и мягкий лимитер. Когда всё выключено, звук идёт без обработки.
- **Скорость без «бурундучьего» голоса.** От 3× медленнее до 3× быстрее, высота тона не меняется.
- **Экономия ресурсов.** Написан на Rust. Маленькая программа, без веб-движка, на паузе ничего не анимируется. Необязательный режим низкого потребления отключает анимации и эффекты для ноутбуков и слабых ПК.
- **Внешний вид под вас.** Светлая, тёмная, чисто чёрная (OLED) тема или как в Windows; 10 акцентных цветов для каждой темы или свой цвет.
- **Ваш язык.** English, Deutsch, Русский, Українська, 中文, 日本語, Français, Čeština, Español, Polski.
- **Бесплатно для личного использования.** См. [Лицензию](#лицензия).

## Возможности

- **Форматы:** MP3, FLAC, OGG/Vorbis, Opus, M4A/AAC, ALAC, WAV.
- **Библиотека:** Треки, Альбомы, Плейлисты и Очереди. Поиск и сортировка везде, порядок меняется перетаскиванием. Альбомы собираются автоматически по тегам. Плейлисты можно складывать в папки; «Понравившиеся» есть всегда. Четыре постоянные очереди для быстрых списков.
- **Папка с музыкой:** выбирается в настройках; Radiant сканирует её при каждом запуске (и по кнопке обновления). Ничего за пределами этой папки не затрагивается.
- **Плеер:** обложка, значок качества (Hi-Res / Lossless, формат, разрядность, частота, битрейт), перемешивание, повтор, плавное включение и выключение, точная перемотка.
- **Тексты песен:** из тегов или из файлов `.lrc` / `.txt` рядом с треком. Синхронные тексты прокручиваются вместе с песней; клик по строке перематывает к ней.
- **Визуализатор:** «солнце» из лучей спектра вокруг обложки, двигается в такт музыке.
- **Сведения о треке:** все теги и технические данные файла.

## Скачивание и установка

Требования: **Windows 10 или 11**, 64 бита.

1. Откройте **[последний релиз](../../releases/latest)** и скачайте сборку для Windows.
2. Распакуйте `.zip` в любую папку (например, `C:\Apps\Radiant`).
3. Запустите `radiant.exe`. Установщика нет, ничего настраивать не нужно; среда выполнения Visual C++ уже встроена.
4. Откройте **Настройки → Library** и выберите папку с музыкой.

Windows может показать сообщение *«Windows защитила ваш компьютер»* (SmartScreen), потому что программа не подписана платным сертификатом. Нажмите **Подробнее → Выполнить в любом случае**. Исходный код открыт, а каждая сборка делается из него в GitHub Actions.

Настройки, плейлисты и модели лежат в `%APPDATA%\Radiant`. Чтобы удалить Radiant, удалите папку с программой и (по желанию) эту папку.

### Настройка ИИ-стемов (необязательно)

Для стемов нужны два дополнительных файла, они не входят в сборку, чтобы программа оставалась маленькой. Без них остальное приложение работает.

1. **`onnxruntime.dll`**
   - Скачайте <https://www.nuget.org/api/v2/package/Microsoft.ML.OnnxRuntime.DirectML/1.22.1> (файл `.nupkg`).
   - `.nupkg` это zip: переименуйте в `.zip` (или откройте в 7-Zip) и возьмите `runtimes/win-x64/native/onnxruntime.dll`.
2. **`DirectML.dll`**
   - Скачайте <https://www.nuget.org/api/v2/package/Microsoft.AI.DirectML/1.15.4>.
   - Откройте так же и возьмите `bin/x64-win/DirectML.dll`.
3. Положите оба файла **рядом с `radiant.exe`**.
4. В Radiant откройте **Настройки → AI & stems** и нажмите **Download** у модели Demucs (один раз, после загрузки файл проверяется). Файл модели можно и импортировать вручную.
5. По желанию включите там **Graphics card (GPU)**: так обработка заметно быстрее. Если видеокарта не подходит, Radiant тихо использует процессор.

Затем: ПКМ по треку → **Create stems** или вкладка **Stems** в плеере. Результаты сохраняются в `Stems/<Исполнитель - Название>/` внутри папки с музыкой и добавляются в плейлист в папке «Stems».

## Что дальше

Radiant активно развивается. Планы, без определённого порядка:

- больше настроек и персонализации;
- дальнейшая оптимизация (процессор, память, скорость запуска);
- улучшение интерфейса;
- больше языков интерфейса;
- медиа-клавиши и системное управление воспроизведением Windows;
- необязательная односторонняя загрузка музыки из облака (Dropbox);
- возможно, скачивание треков напрямую из других сервисов;
- поддержка NFC-ключа для разблокировки приложения;
- версия для Linux;
- установщик и многое другое.

Идеи и сообщения об ошибках приветствуются в [Issues](../../issues).
